Channel plan once done

┌─────────┬─────────────┬─────────────┐
│ Band │ Main router │ Old router │
├─────────┼─────────────┼─────────────┤
│ 2.4 GHz │ 1 (or 6) │ 11 │
├─────────┼─────────────┼─────────────┤
│ 5 GHz │ 36 │ 149 (or 44) │
└─────────┴─────────────┴─────────────┘

After you apply the changes, reconnect your laptop to the old router's Wi-Fi and run ipconfig. The gateway should still be 192.168.1.1 and your address should be in .10–.200.

If the old router has no 5 GHz band, ignore the 5 GHz row for it.
